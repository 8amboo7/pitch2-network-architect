# Pitch 2 — Network Architect

แบบจำลองเครือข่าย APJC ในรูปแบบ 3 มิติ

## ไฟล์ในโปรเจกต์

- `index.html` — จุดเริ่มต้นสำหรับ Vercel และลิงก์ไปยังแบบจำลอง
- `pitch2-network-architect.html` — โมเดลเครือข่าย 3 มิติแบบไฟล์เดียว เปิดได้โดยตรง

## เปิดดู

- เว็บไซต์: https://infra3d.vercel.app/
- โมเดลโดยตรง: https://infra3d.vercel.app/pitch2-network-architect.html

การเปลี่ยนแปลงบน branch `main` จะเริ่ม deployment ผ่าน Vercel โดยอัตโนมัติ
